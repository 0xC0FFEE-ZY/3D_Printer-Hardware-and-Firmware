# 0xC0FFEE_ZY_3DPrinter

> **本仓库所有硬件已制作出实物并正常运行。** 

自制的 3D 打印机开源项目，包含整机三维建模、主板与电机驱动电路设计、配套的 Klipper、Marlin 固件、CAD 结构件等。

- 可观看一分钟介绍短片：https://b23.tv/UroBLIZ


## 仓库内容

| 目录 / 文件 | 说明 |
| --- | --- |
| `三维建模` | 本 3D 打印机整体三维结构建模；打印机屏幕外壳（适用于 MKS TFT35） |
| `硬件设计_工程文件（原理图+PCB）` | 嘉立创工程，本 3D 打印机的主板、电机驱动电路设计 |
| `Klipper` | 本打印机配套 Klipper 固件 |
| `Chinese_Version_Configured_Marlin2.1.3` | 本打印机配套 Marlin 固件 |
| `CAD图纸_3D打印机结构件` | 本打印机的一些结构件，可以找商家加工定制 |
| `XY_DrawCircles` | XY 轴测试程序 |
