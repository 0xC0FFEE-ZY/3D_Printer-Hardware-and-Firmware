## 硬件优化更新说明（2026-11-09）

> **为了同时兼容 Klipper 固件，主板电路有微小改动，主要改动内容为删去了 X2 和 Y2 电机的 DIAG 引脚（仅此一处改动）。**

- 旧版硬件在 Marlin 固件中完全正常；但在 Klipper 中，无传感器回零无法正常使用，新改版硬件解决了这一故障。
- 已经制作旧版硬件的用户无需重新打板焊接，旧版硬件在 Marlin 中正常使用；如果固件更换为 Klipper，只需拆掉 X2、Y2 电机驱动上的 DIAG 针脚即可。
